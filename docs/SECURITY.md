# 安全与权限模型

版本：V1.0

## 威胁模型
系统摄入网页、视频字幕、文档、代码和操作记录，均视为不可信数据。内容可能包含提示注入、恶意脚本、数据外传指令、伪造步骤或过期信息。模型也可能误解任务、幻觉工具结果或尝试越权。不能依赖模型自我约束，必须由运行时权限强制执行。

## 原则
- 外部资料与系统指令分层，资料不得获得指令优先级。
- 模型不能自行授予权限、修改策略或批准高风险操作。
- 工具默认拒绝，按专家、任务、资源和时间授予最小权限。
- 技能先在隔离环境审查和测试，再进入正式技能库。
- 外部副作用记录调用者、参数摘要、审批人和结果。
- 密钥不得写入提示词、技能包、日志或仓库。

## 权限等级
- L0 只读：检索资料、读取页面、分析文件。
- L1 低风险写入：专家工作区草稿、报告和临时文件。
- L2 可逆操作：沙箱或测试环境中的修改和任务。
- L3 外部副作用：对外发布、发送消息、账号授权、支付、删除正式数据、修改生产配置等，必须人工审批。

权限按工具、资源、专家、任务和时间范围组合授权。技能通过测试不意味着自动获得更高权限。

## 沙箱
默认无网络或仅允许白名单网络；文件系统限定任务目录；禁止访问宿主凭据和无关目录；限制进程、CPU、内存、时长和输出；锁定依赖；测试数据与生产数据分离；保留日志并可销毁临时环境。

## 提示注入防护
外部内容只作为数据引用；提取时识别忽略指令、泄露密钥、下载执行等风险；技能生成阶段策略扫描与人工复核；工具层独立验证参数、域名、路径和权限；网页或技能文本不得修改系统策略。

## 人工审批
审批信息包含动作、目标、参数、影响范围、风险、发起专家、任务和撤销方式。审批绑定具体动作与参数，参数变化必须重新审批。模型不能伪造审批结果。

## 审计响应
记录身份、任务、专家、技能版本、工具调用、权限决策、审批、结果和异常。发现越权或泄露迹象时暂停相关专家/技能、撤销凭据、保全日志并复盘。
