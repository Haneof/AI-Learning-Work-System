# AI Learning & Work System

通用型 AI 自主学习与工作系统：将专业资料转化为可追溯知识、可执行技能和经过实战验证的经验，培养可独立完成专业工作的 AI 专家。

## 核心原则
- 通用底座、专业隔离：模型和基础设施共享，各专家的知识、技能、记忆、经验及评估标准隔离。
- 从资料到能力：资料只是输入，知识、技能和经验才是核心资产。
- 实战验收：不能以复述教程认定学会，必须通过任务测试。
- 学习与工作闭环：工作发现缺口，触发学习；新能力通过测试后才进入正式技能库。
- 证据可追溯：知识和技能保留来源、时间戳、适用条件与版本。
- 安全优先：外部资料视为不可信输入，高风险操作需要人工批准。

## 当前模型与设备基线
- 主模型方向：本地无审查 Qwen 3.5，4B 与 9B 两个候选版本，需同一测试集对比后确定。
- 原型设备：Windows、NVIDIA 8GB VRAM、16GB RAM。
- 主模型必须可切换；视觉、OCR、ASR、视频处理作为专用模块。
- 精确模型 ID、量化格式、视觉输入能力和部署后端尚待核实。
